# HBTS 진로·학습 설계 툴

HBTS 뇌 사고유형 검사 결과지를 **학생이 읽고 바로 실행할 수 있는 진로·학습 설계서**로 바꾸는 도구입니다.

주식회사 뿌리깊이 · 내부 사용

---

## 쓰는 법

`index.html` 을 브라우저에서 열고, **결과지 PDF를 끌어다 놓으면** 됩니다.

```
결과지 PDF
   ↓ 이름 · 검사일 · 외향/내향 · 감정 비율   → 자동 추출
   ↓ 네 영역 점수                          → AI Vision 판독
   ↓ 기하 검산                             → 오판독 자동 검출
   ↓ 학년만 직접 선택
설계서 9개 섹션 + 교사·학부모용 가이드
```

인터넷 없이도 열립니다. PDF 엔진(pdf.js)이 파일 안에 들어 있습니다.

### 두 가지 판독 경로

| 결과지 형태 | 처리 |
|---|---|
| 일반 PDF (글자가 텍스트) | 텍스트는 정규식으로, **점수 4개만** Vision 판독 |
| 인쇄→PDF 저장본 (글자가 전부 이미지) | 앞 8페이지를 **Vision 이 통째로 판독** |

두 번째 경우는 자동으로 감지됩니다. 전체 텍스트가 300자 미만이면 스캔본으로 봅니다.

### API 키

점수 판독과 AI 심화 설계에 Claude API 키가 필요합니다.
**한 번만 입력**하면 브라우저에 저장됩니다.

- 발급: console.anthropic.com → API Keys
- 비용: 학생 1명당 100원 안팎
- 키는 브라우저에만 저장되며 어떤 서버로도 전송되지 않습니다

키가 없어도 **점수를 직접 입력하면 설계서는 정상 생성**됩니다.

## 고칠 때

콘텐츠만 바꾸려면 아래 세 파일만 건드리면 됩니다.

| 파일 | 내용 |
|---|---|
| `src/kb.js` | 네 영역(LAB·LPB·RAB·RPB) 특징 · 진로 지도 · 조합 |
| `src/science.js` | 학습법 4기법 · 유형별 진입로 · 시험 계획 |
| `src/roadmap.js` | 학창시절 로드맵 · 제도 정보 · 약점 대응 |

```bash
./build.sh      # src/ → index.html 다시 생성
```

| 그 외 파일 | 역할 |
|---|---|
| `src/shell.html` | 레이아웃 · CSS · 입력 화면 |
| `src/engine.js` | 점수 해석 · 설계서 렌더링 · 시각화 · AI 호출 |
| `src/upload.js` | PDF 판독 (텍스트 / 스캔본 두 경로) |
| `src/verify.js` | 기하 검산 |

## ⚠️ 콘텐츠를 고칠 때 반드시 지킬 것

### 1. 강의자료 p10~p15 라벨은 뒤바뀌어 있습니다

`HBTS 검사에 따른 맞춤 진로 및 학습법` 자료의 p10~15에서 「우측 전뇌」와 「우측 후뇌」가 **서로 바뀌어** 있습니다.
같은 자료 p3(4분면 그림) · p25~32(학습전략) · p33~36(표) · 공식 결과지 18p는 모두 아래가 맞습니다.

```
RAB 우측전뇌 = 시각 · 공간 · 창의 · 변화
RPB 우측후뇌 = 사람 · 공감 · 화합 · 감성
```

**이 저장소의 `kb.js` 는 교정된 기준을 씁니다.** 원본 자료를 보고 되돌리지 마세요.

### 2. 학습유형 이론은 연구로 지지되지 않습니다

- 「선호하는 방식으로 배우면 더 잘 배운다」(meshing 가설)는 여러 실험에서 지지되지 않았습니다.
- 좌뇌형/우뇌형 구분은 1,011명 fMRI 연구에서 발견되지 않았습니다.

그래서 이 툴의 구조는 이렇습니다.

```
무엇을 할지(WHAT)    →  모두 같다        (메타분석으로 검증된 4기법)
어떻게 시작할지(HOW)  →  유형별로 다르다  (첫 주 이탈을 막는 진입로)
```

**절대 쓰면 안 되는 문장**

- 「창의형은 그림으로 공부하면 더 잘 외운다」
- 「우뇌형이라 수학보다 예체능이 맞다」
- 「뇌과학이 증명한 맞춤 학습」

### 3. 결과지 원문을 그대로 옮기지 않습니다

```
결과지 문장 그대로 복사      ❌
결과지 직업표 그대로 전재     ❌  → 참고해 우리 기준으로 재구성
검사 문항을 툴에 넣기        ❌
우리가 작성한 해석 문장       ✅
```

### 4. 개인정보

**검사 결과지 PDF 는 이 저장소에 올리지 않습니다.** `.gitignore` 로 막아두었습니다.
학생 이름·점수가 담긴 파일이 커밋되지 않도록 주의하세요.

툴 자체는 업로드한 PDF를 **브라우저 안에서만 처리하고 어디에도 저장하지 않습니다.**

## 학습법 4기법의 근거

| 기법 | 근거 |
|---|---|
| 꺼내기 | 4번 다시읽기 40% vs 1번읽고 3번꺼내기 61% (1주일 뒤) — Roediger & Karpicke 2006 |
| 나눠서 | 복습 간격은 시험까지 남은 기간의 10~20% — Cepeda 외 2008 |
| 설명하기 | 자기설명 g=0.55 / 형광펜 d=0.44 — Bisra 외 2018 |
| 섞어서 | 중학 수학 787명, 단원별 37% vs 섞어서 61% — Rohrer 외 2020 |

⚠️ **영단어·한자는 섞으면 오히려 해롭습니다** (g=−0.39, Brunmair & Richter 2019).
이 예외는 반드시 유지하세요.
